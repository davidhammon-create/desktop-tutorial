# 🧬 Interactive 3D Models Website

Eine moderne Webanwendung für Studenten zur interaktiven Visualisierung komplexer wissenschaftlicher Konzepte in 3D.

## Features

✨ **Hochdetaillierte 3D-Modelle**
- Quantencomputer mit animierten Komponenten
- Molekülstrukturen mit Bindungen
- Atomare Strukturen mit Elektronenorbitalen
- DNA-Doppelhelix mit Nukleotiden

🎮 **Interaktive Steuerung**
- **Maus-Drag**: Rotation
- **Scroll**: Zoom ein/aus
- **R-Taste**: Zurücksetzen
- Smooth 3D-Navigation

🎨 **Moderne Benutzeroberfläche**
- Responsive Design
- Dark/Light Theme Support
- Seitliche Navigation
- Detaillierte Beschreibungen

⚡ **Performance**
- Three.js optimiert
- Echtzeit-Rendering
- Smooth Animationen

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

Die Website öffnet sich automatisch auf `http://localhost:5173`

## Build

```bash
npm run build
```

## Technologien

- **React** - Benutzeroberfläche
- **Three.js** - 3D-Grafiken
- **Vite** - Build-Tool
- **Modern CSS** - Responsive Design

## Modelle

### 1. Quantencomputer
Detaillierter Aufbau eines Quantencomputers mit:
- Kühlsystem
- Quantum Processing Unit mit Puls-Animation
- Schaltkreise und LED-Indikatoren
- Goldene Verbindungskabel

### 2. Molekülstruktur
Komplexes Molekülmodell mit:
- Verschiedenen Atomen (Kohlenstoff, Wasserstoff, Sauerstoff)
- Chemischen Bindungen
- Realistische Farben und Metallglanz

### 3. Atomare Struktur
Bohr-Atommodell mit:
- Protonenkern
- Drei Elektronenschalen
- Animierte Elektronenorbitale
- Farbkodierte Schalen

### 4. DNA-Helix
Doppelhelix-Struktur mit:
- Zwei Stränge (Rot/Blau)
- Basenpaarverbindungen
- Nukleotidkugeln
- Sanfte Rotationsanimation

## Steuerung

| Aktion | Effekt |
|--------|--------|
| Maus-Drag | Objekt rotieren |
| Scroll-Rad | Zoom ein/aus |
| Rechts-Klick Drag | Pan (verschieben) |
| R-Taste | Ansicht zurücksetzen |
