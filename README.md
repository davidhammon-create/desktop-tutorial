# AboWandler

KI-Finanz & Abo-Check App — findet vergessene Abos und verdächtige Abbuchungen und zeigt, was aus dem Geld werden könnte, wenn es stattdessen in einen ETF investiert wird.

Built with React + Vite.

## Entwicklung

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
